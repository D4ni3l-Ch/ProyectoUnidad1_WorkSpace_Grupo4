## 2. Descripción del Proyecto (Caso Asignado)

Plataforma web diseñada para gestión y alquiler de espacios compartidos para profesionales y empresas. Las funcionalidades incluyen consulta de disponibilidad en tiempo real, reserva por horas de escritorios y salas de reunión, selección de recursos adicionales (proyector, catering), control estricto de aforo y emisión de pases de acceso mediante código QR.

## 3. Instrucciones de Ejecución
### 3.1 Requisitos Previos
- Visual Studio Code
- Node.js (LTS) + npm
- Código fuente del proyecto
### 3.2 Verificación de Instalación
- Abrir Terminal de VS Code
- Ejecutar comandos "node -v", "npm -v" para verificar instalación.
- Abrir carpeta del código fuente con VS Code
### 3.3 Ejecución en Servidor Local
- En la Terminal (CMD) de VS Code ejecutar el comando "npm install"
- Una vez instalado, ejecutar "npm run" para visualizar opciones
- Ejecutar comando "npm run dev"
- Obtener la dirección localhost en la Terminal
- Ingresar la dirección obtenida en un navegador web
